### Reminders the agent will enforce for you
- Brand is **Comentify** (one m).
- **No prices or specific limits** on the page — those live only on Plans; the agent links there.
- **No speed or setup-time promises** ("go live in minutes", "replies within seconds").
- No developer jargon (OAuth, access token, webhook).
- Screenshots become plain markdown images with descriptive alt text written for you.
- Every label you give gets checked before it ships.
